# Python Calculator

A simple command-line calculator built using Python.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Power calculation
* Square root
* Error handling

## Technologies Used

* Python 3.x

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/ShikharPandey0170/python-calculator.git
cd calc
```

2. Run the application:

```bash
python calculator.py
```
